# Docker Based Project

A hands-on project for learning Docker, containerization, and multi-container application development.

## Goals

- Learn the fundamentals of Docker
- Create and manage Docker images and containers
- Containerize a Python application
- Learn Docker Compose
- Connect multiple containers
- Experiment with persistent storage and environment variables
- Explore basic CI/CD concepts

## Probable Tech Stack

- Python
- FastAPI
- Docker
- Docker Compose
- PostgreSQL
